# 🇹🇷 Türkçe Duygu Analizi (BERT)

Bu proje, Türkçe metinler üzerinde **duygu analizi (sentiment analysis)** yapmak için
fine-tune edilmiş bir **BERT tabanlı derin öğrenme modeli** içermektedir.
Model, kullanıcıdan alınan metni analiz ederek duygu tahmini üretir ve
**Streamlit** ile geliştirilen bir web arayüzü üzerinden sunulur.
